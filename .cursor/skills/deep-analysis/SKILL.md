# 美股公司深度分析

对用户给出的美股代码（如 `CRWV`、`AAPL`），自动输出完整深度分析报告。**默认中文**，数据以实时公开来源为准。

## 触发方式

以下任一形式即启动本技能，无需额外确认：

- `分析 CRWV`
- `深度分析 AAPL`
- `美股公司分析 NVDA`
- `CRWV 投资评级`

若仅给出 ticker 无动词，结合上下文判断；明确为研究/分析意图时同样适用。

## 工作流程

1. **解析 ticker**：确认美股代码、是否 ADR、主要上市交易所（NYSE/NASDAQ）。
2. **拉取数据**（必须联网，禁止凭记忆编造财务数字）：
   - 公司概况、业务描述、最新股价与市值
   - 最近 2–3 年营收/利润及分部结构（10-K/10-Q、IR 页面）
   - 管理层名单与背景（DEF 14A、公司官网）
   - 行业格局与主要竞争对手
   - 最新财报、指引、分析师共识（如有）
   - 近期重大新闻与监管/诉讼风险
3. **可选加速**：若本地可用，运行 Wall Street 技能脚本快速取数：
   ```bash
   python3 ~/.codex/skills/wall-street-us-stock-analysis/scripts/market_data.py TICKER --period 1y --json
   ```
4. **按固定模板输出**：严格使用下方十段结构，顺序与标题不得改动。
5. **标注数据时点**：报告开头注明数据截止日期与主要来源。

## 固定输出结构

必须完整输出以下 **10 个章节**，不得省略、合并或改名：

```markdown
# [公司全称]（[TICKER]）深度分析报告

> 数据截至：YYYY-MM-DD | 主要来源：[列举]

## 公司介绍
[成立时间、总部、主营业务、上市情况、市值/股价快照]

## 商业模式
[价值主张、客户群体、产品/服务如何交付、关键运营环节]

## 收入来源
[按产品/地区/客户类型拆分；附最近财年或 TTM 占比与趋势]

## 盈利模式
[毛利率/营业利润率驱动因素；定价权、规模效应、经常性收入占比等]

## 管理层
[CEO/CFO 及核心团队背景、任期、持股与薪酬要点、治理评价]

## 行业地位
[细分市场规模、市占率或排名、与主要竞品对比]

## 核心竞争优势
[护城河：技术、网络效应、品牌、成本、监管牌照、转换成本等，附证据]

## 风险
[业务、财务、竞争、监管、宏观、执行等风险；区分高/中/低并说明触发条件]

## 未来三年增长点
[可量化催化剂：新产品、新市场、提价、降本、并购、行业顺风等；按时间线排列]

## 投资评级
[给出明确评级：强烈买入 / 买入 / 持有 / 减持 / 卖出]
[目标价区间或估值区间（如适用）、核心逻辑摘要（3–5 条）、主要下行/上行情景]
```

## 章节写作要求

| 章节 | 最低要求 |
|------|----------|
| 公司介绍 | 2–4 段，含 ticker、交易所、市值 |
| 商业模式 | 说清楚「谁付钱、为什么付钱、怎么规模化」 |
| 收入来源 | 有分部或业务线占比；数据缺失时说明并给定性判断 |
| 盈利模式 | 连接收入结构与利润率，引用最新毛利率/营业利润率 |
| 管理层 | 至少覆盖 CEO + CFO；提及关键继任或治理风险 |
| 行业地位 | 与 2–3 家直接竞品对比 |
| 核心竞争优势 | 至少 3 条可验证优势，避免空泛形容词 |
| 风险 | 至少 5 条，含 1 条市场可能低估的风险 |
| 未来三年增长点 | 按年度或阶段列出，区分确定性高/中/低 |
| 投资评级 | 必须给出单一明确评级 + 1 段理由 |

## 分析标准

- 区分**事实**（财报/公告）与**判断**（评级、预测）。
- 优先使用 SEC 申报文件、公司 IR、Yahoo Finance、Bloomberg 等可引用来源。
- 新股或数据稀缺公司：明确标注信息缺口，用定性分析补足，不虚构数字。
- 报告末尾一行免责声明：`以上内容仅供参考，不构成投资建议。`

## Examples

**输入：**
```
分析 CRWV
```

**输出：** 按上述十段结构输出 CoreWeave（CRWV）完整报告，含 GPU 云商业模式、收入结构、与 NVDA/ hyperscaler 关系、债务与扩张风险、AI 基建行业地位，以及明确投资评级。

**输入：**
```
深度分析 AAPL，重点看服务业务增长
```

**输出：** 同样十段结构；在「收入来源」「未来三年增长点」中加重 Apple Services 与硬件生态协同分析，其余章节仍须完整。
