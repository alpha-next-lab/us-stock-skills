# 美股公司深度分析

对用户给出的美股代码（如 `CRWV`、`AAPL`），输出可交易的深度报告。**默认中文**。财务数字必须来自当次拉取的公开来源，禁止凭记忆编造。

评级、估值方法和行业覆盖层的数字门槛以 [report-template.md](report-template.md) 为准。写评级前必须读该文件。

## 触发方式

以下任一形式即启动本技能，无需额外确认：

- `分析 CRWV`
- `深度分析 AAPL`
- `美股公司分析 NVDA`
- `CRWV 投资评级`

若仅给出 ticker 无动词，结合上下文判断；明确为研究或分析意图时同样适用。

## 工作流程

1. **解析标的**：确认美股代码、交易所（NYSE/NASDAQ）、是否 ADR、行业（用于覆盖层：银行、保险、REIT、生物科技或尚未盈利、一般经营公司）。
2. **拉取行情与共识**（本地脚本可用时先跑；失败则改走网页，不得跳过取数）：

   ```bash
   python3 ../daily-analysis/scripts/market_data.py TICKER --period 1y --json
   ```


3. **拉取基本面**（财报实际数以最新 10-K/10-Q 与公司 IR 为准，Yahoo 只做交叉检查）：
   - 分部收入、利润率、现金流、现金与债务、SBC、稀释后股数
   - 管理层、薪酬、资本配置（DEF 14A）；可得时看 Form 4
   - FY1/FY2 共识收入与 EPS（Yahoo Analysis 或同等公开共识页）
   - 直接竞品、近期指引、监管与诉讼
4. **对账后再下笔**。现价、稀释后股数、股权价值、净债务、企业价值互相勾稽。偏差处理见 [report-template.md](report-template.md)。
5. **按固定结构输出**。`投资结论` 与 `投资评级` 必须是同一评级、同一现价、同一 12 个月目标价。结论只写摘要；估值过程只在 `投资评级` 展开。
6. **文首标注时点**：数据截止日期、现价时间、主要来源。每个关键数字在句中或表注标明文件与期间（例如「FY2025 10-K」），不要只在文首列来源。

## 固定输出结构

必须完整输出以下章节，顺序与标题不得改动。用户要求侧重某业务时，在相关章节加重，其余章节仍须达到最低要求。

`附录：持仓与拥挤度` 仅在短期利息、机构持仓变化或期权拥挤度有公开数据时输出；没有数据则整节省略。

```markdown
# [公司全称]（[TICKER]）深度分析报告

> 数据截至：YYYY-MM-DD | 现价：$XX（时点） | 主要来源：[列举]

## 投资结论
[单一评级；期限 12 个月；现价；12 个月基准目标价；隐含总回报（含股息，无股息则注明）；置信度高/中/低]
[差异化观点：共识已相信什么；本报告差在收入、利润率、倍数、资产负债表、资本配置中的哪一项；下一个会改预测的 KPI]
[核心逻辑 3 条]

## 公司介绍
## 商业模式
## 收入来源
## 盈利模式
## 财务质量
## 管理层
## 行业地位
## 核心竞争优势
## 风险
## 未来三年增长点
## 投资评级
```

## 章节最低要求

未达到下列要求不得交付。详细表格与行业替换指标见 [report-template.md](report-template.md)。

| 章节 | 最低要求 |
|------|----------|
| 投资结论 | 评级、12 个月期限、现价、基准目标价、隐含总回报、置信度、差异化观点、3 条逻辑。数字与文末评级一致 |
| 公司介绍 | 2–4 段，含 ticker、交易所、市值。ADR 写明 VIE、双重股权或预扣税是否适用 |
| 商业模式 | 谁付钱、为什么付钱、怎么规模化；合同是一次性还是订阅 |
| 收入来源 | 分部或业务线占比与趋势。可得时写前十大客户或客户集中度；缺失则标明 |
| 盈利模式 | 连接收入结构与利润率，引用最新毛利率与营业利润率（行业覆盖层允许替换指标），并与 1–2 家同业比较 |
| 财务质量 | FCF 及转化率；现金、总债务、净债务；市值到企业价值的桥；稀释后股数、近一年股本变化、SBC；声明估值用 GAAP 还是 non-GAAP |
| 管理层 | CEO 与 CFO。另写指引兑现（近几个季度或全年修正；无历史则标明）、回购/增发/分红/并购、可得时的内部人交易，以及继任或治理风险 |
| 行业地位 | 与 2–3 家直接竞品对比。有来源时给 TAM 与份额趋势 |
| 核心竞争优势 | 至少 3 条。每条为：优势、证据、可持续性（强/中/弱） |
| 风险 | 至少 5 条，含 1 条市场可能低估的风险。每条含触发条件、粗概率、对 12 个月目标价的方向与幅度 |
| 未来三年增长点 | 先给 FY1/FY2 收入、利润率（或覆盖层指标）、EPS、FCF，并列本报告与共识。再给带日期的催化剂，以及超预期或低于预期时改哪一项预测。共识未取得必须写明，不得留空或用记忆填数 |
| 投资评级 | 单一评级；与结论相同的现价与目标价；至少两种估值方法（远期倍数，加上同业比较或历史区间；长久期成长另做反向 DCF）；牛/基/熊的价格、假设与概率（合计 100%）及概率加权价值；3–5 条逻辑；关键假设；证伪条件。同业折溢价只解释增长、利润率或风险，不单独决定评级 |

银行、保险、REIT、生物科技或尚未盈利公司：在盈利模式、财务质量、投资评级中改用 [report-template.md](report-template.md) 的覆盖层指标，不要硬套毛利率或市盈率。

## 分析标准

- 区分**事实**（财报、公告、可引用共识）与**判断**（评级、本报告预测、目标价）。
- 财报实际数以 SEC 申报或公司 IR 为准。市价、市值、共识、持仓可用 Yahoo。两边冲突时并列，并写明估值采用哪一套。
- 新股或数据稀缺：逐项标注缺口，用定性补足，不虚构数字。缺共识时仍给本报告 FY1/FY2，并降低置信度。
- 评级按 12 个月概率加权总回报和风险收益比确定，须与风险、预测两章自洽。三年经营路径是论点期限，目标价窗口仍是 12 个月。
- 避免虚假精度。不确定的输入用区间；情景概率是判断，不是测量值。
- 报告末尾一行免责声明：`以上内容仅供参考，不构成投资建议。`

## Examples

**输入：**

```
分析 CRWV
```

**输出：** 完整结构。投资结论先给 12 个月评级与目标价，并写明相对共识差在增速、利润率还是杠杆。财务质量必须含净债务、稀释与 FCF。未来三年增长点含 FY1/FY2 对共识。投资评级用至少两种方法，并给牛/基/熊价格与概率。

**输入：**

```
深度分析 AAPL，重点看服务业务增长
```

**输出：** 同样结构。收入来源、预测与估值里加重 Services 对毛利率和倍数的影响。其余章节仍须达到最低要求。
