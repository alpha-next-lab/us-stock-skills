# 报告模板补充说明

写评级、预测和估值时以本文件为准。`SKILL.md` 的章节最低要求与本文件同时满足；两边冲突时，采用要求更完整的一方，并保持投资结论与投资评级的评级、现价、目标价一致。

## 投资评级口径

期限一律为 **12 个月**。总回报 =（目标价 − 现价）/ 现价 + 预期股息率。无股息时注明总回报等于价格回报。

概率加权总回报 = Σ（情景概率 × 该情景价格回报）+ 股息率。情景概率合计 100%，基准情形概率通常最高。概率是判断，需在文中标明。

| 评级 | 12 个月概率加权总回报 | 同时满足 |
|------|------------------------|----------|
| 强烈买入 | ≥ 25% | 基准情形上行 ≥ 20%，且基准上行空间 / 熊市下行空间 ≥ 2 |
| 买入 | ≥ 12% | 基准上行空间大于熊市下行空间 |
| 持有 | −8% 至 +12% | 上下行大致相当 |
| 减持 | ≤ −8% | 熊市下行空间大于基准上行空间 |
| 卖出 | ≤ −20% | 或商业模式、流动性、偿债已经结构性受损 |

两个条件冲突时，取更接近「卖出」的一档，并说明冲突来自回报还是风险收益比。

同业折价或溢价只作为估值输入。必须说明折溢价来自增长、利润率还是风险。不得再把「低于同业 20%」单独当作强烈买入。

评级须与「风险」「未来三年增长点」的数字自洽：目标价用的利润率、股数和净债务，要能在这两章找到。

## 数据对账

下笔前核对：

- 估值采用的现价 × 稀释后股数 ≈ 股权价值。与 Yahoo `marketCap` 偏差超过 5% 时，并列两套数字，说明股数是基本还是稀释、价格时点，并声明估值采用哪一套。
- 企业价值 ≈ 股权价值 + 总债务 − 现金 + 少数股东权益 + 优先股。缺失项目单列，不要并进残差还不说明。与 Yahoo `enterpriseValue` 偏差超过 10% 时并列并说明。
- 利润表、现金流量表、资产负债表的实际数以最新 10-K/10-Q 或公司 IR 为准。Yahoo 的利润率、FCF、债务只做交叉检查。
- 共识收入、共识 EPS 来自 Yahoo Analysis 或同等公开共识页。脚本里的 `epsForward`、`targetMeanPrice` 可以引用，但要标明是远期 EPS 与目标价均值，不要把它写成完整的 FY 收入共识。
- 脚本没有、网页也没有的字段写「共识未取得」或「未披露」。不得用记忆填数。
- 仅当 `bloomberg.available == true` 或用户提供终端导出时，才把 Bloomberg 列入来源。

每个关键数字在句中或表注标明期间与文件，例如「FY2025 10-K」「Yahoo 报价 2026-09-22」。

## 投资结论

放在正文第一节，只摘要，不展开估值公式：

1. **评级**
2. **期限**：12 个月
3. **现价**与时点
4. **12 个月基准目标价**
5. **隐含总回报**（含股息；无股息则注明）
6. **置信度**：高 / 中 / 低。缺共识、缺完整财年或资本结构不清时，不得给「高」
7. **差异化观点**：共识相信什么；本报告差在收入、利润率、倍数、资产负债表、资本配置中的哪一项；下一个会改预测的 KPI
8. **核心逻辑** 3 条

## 各章节展开提示

### 公司介绍

- 一句话定位（「XX 行业的 XX 类型公司」）
- 关键里程碑：IPO、重大并购、业务转向
- 当前规模：TTM 营收、员工数（如有）
- ADR：VIE、投票权差异、预扣税、双重上市价差。不适用则写「普通股，无 ADR 结构」

### 商业模式

- 客户 → 渠道 → 产品 → 收入 → 成本结构
- B2B / B2C / B2B2C；合同是一次性还是订阅，以及典型期限

### 收入来源

| 业务线 | 占比 | YoY | 备注 |
|--------|------|-----|------|
| ... | ...% | ...% | 来源与期间 |

可得时补充前十大客户占比或单一客户是否超过 10%。未披露则写明。

### 盈利模式

- 单位经济（适用时）：ARPU、贡献利润、产能利用率、经常性收入占比
- 与 1–2 家同业的利润率对比
- 行业覆盖层替换毛利率、营业利润率时，在本节声明替换原因

### 财务质量

必须写清：

- 经营现金流、FCF。转化率优先用 FCF / 净利润；净利润为负或失真时改用 FCF / 收入，并说明原因
- 现金、总债务、净债务
- 市值、企业价值，以及差额来自债务、现金还是其他请求权
- 稀释后股数、近一年股本变化、SBC（金额及占收入比，可得时）
- 估值与 EPS 使用 GAAP 还是 non-GAAP；一次性项目、重组、并购会计是否扭曲了利润率

### 管理层

| 姓名 | 职位 | 任期 | 背景要点 |
|------|------|------|----------|
| ... | CEO | ... | ... |

履历之外必须写：

- 指引兑现：近 4 个季度相对共识，或近一年全年指引的上调/下调。历史不足则标明
- 资本配置：回购、增发、分红、主要并购及其资金来源
- 内部人交易：可得时摘要 Form 4 的方向与规模；不可得则标明
- 继任或治理上的具体风险

### 行业地位

- TAM/SAM（有来源则引用，无来源不编市场规模）
- 市占率趋势：扩大 / 稳定 / 收缩
- 2–3 家直接竞品：业务重叠点，而不是只列公司名

### 核心竞争优势

每条格式：**优势** — 证据（客户留存、转换成本、份额、监管牌照、成本曲线等可核对事实）— 可持续性（强/中/弱）

### 风险

格式：**[高/中/低] 风险名称** — 触发条件 — 粗概率 — 对 12 个月目标价的方向与幅度

至少 5 条，其中 1 条是市场定价里可能偏轻的风险。幅度可以用「目标价下修约 X%」或「每股价值减少约 $X」。做不到定量时，写方向并标明「幅度未量化」，不得省略该风险。

### 未来三年增长点

先写预测，再写催化剂。预测是判断，列在「本报告」列；共识列只填当次查到的数字。

| 指标 | 最近财年实际 | FY1 本报告 | FY1 共识 | FY2 本报告 | FY2 共识 |
|------|----------------|------------|----------|------------|----------|
| 收入 | | | | | |
| 营业利润率（或覆盖层指标） | | | | | |
| EPS（注明 GAAP 或 non-GAAP） | | | | | |
| FCF | | | | | |

财年标签写明是会计年度还是自然年，不要把 TTM、FY1、NTM 混在同一列而不注明。

催化剂：

| 日期或窗口 | 事件 | 确定性 | 若超预期 | 若低于预期 |
|------------|------|--------|----------|------------|
| YYYY-MM 或窗口 | ... | 高/中/低 | 改 FY1 的哪一项、目标价方向 | 同上 |

三年经营路径可以在表后用短文说明，但不得替代上表。增长叙事若只抬收入、不抬每股价值，要指出 SBC、增发或资本开支的拖累。

### 投资评级

与投资结论使用同一评级、同一现价、同一基准目标价。本节只负责把价格算出来。

1. **评级**
2. **现价、12 个月基准目标价、隐含总回报**
3. **至少两种方法**
   - 远期倍数：写明 P/E、EV/EBITDA、EV/Sales、P/FCF 或覆盖层倍数，以及年份（FY1 或 NTM）和 GAAP/non-GAAP
   - 同业比较或自身历史区间，至少做其中一项；数据都有则两项都做
   - 长久期、利润率或终值假设主导股价时，另做反向 DCF：写明要兑现的增速与利润率，市场隐含值是否高于本报告 FY1/FY2
   - 分部经济学差异大时用分部加总，不用单一集团倍数
4. **同业表**（做同业比较时）

| 公司 | 倍数 | 年份与口径 | 预期增长 | 相对本报告标的 |
|------|------|------------|----------|----------------|
| ... | | | | 折价/溢价及原因 |

5. **情景**

| 情景 | 概率 | 关键假设 | 目标价 | 相对现价 |
|------|------|----------|--------|----------|
| 牛市 | | | | |
| 基准 | | | | |
| 熊市 | | | | |
| 概率加权 | 100% | | | |

6. **核心逻辑** 3–5 条
7. **关键假设**：哪些必须成立，评级才有效
8. **证伪条件**：哪一个数据或事件出现就下调评级，并指回风险章节

## 行业覆盖层

命中下列类型时，替换不适用的毛利率或市盈率，并在盈利模式开头声明。其余章节仍要写。

| 类型 | 用这些指标 | 估值锚 |
|------|------------|--------|
| 银行 | 净息差、信贷成本、CET1、ROTCE | P/TBV、远期 P/E |
| 保险 | 综合成本率、投资收益、账面价值 | P/B、远期 P/E |
| REIT | FFO/AFFO、出租率、资本化率 | P/FFO、NAV |
| 生物科技或尚未盈利 | 管线阶段、现金跑道、烧钱速度 | 现金加上管线情景；不用市盈率 |
| 高增长但亏损 | 收入增速、毛利率路径、FCF 转正时点、稀释 | EV/Sales；目标价必须扣净债务和稀释 |

一般经营公司仍用毛利率、营业利润率、EPS 与 FCF。

## 附录：持仓与拥挤度

仅在数据可得时输出，有什么写什么。可以包括：空头占流通股比例及天数、机构持仓环比变化、主要股东集中度。没有数据则整节省略，不要写「暂无」。

此附录不改变评级。评级仍由 12 个月基本面回报决定。
