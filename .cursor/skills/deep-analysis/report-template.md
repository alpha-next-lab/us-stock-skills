# 报告模板补充说明

## 投资评级口径

| 评级 | 含义 | 典型条件 |
|------|------|----------|
| 强烈买入 | 显著低估，高确信度上行空间 | 估值低于同业 20%+ 且催化剂明确 |
| 买入 | 正面风险收益比 | 基本面改善或合理估值下的成长 |
| 持有 | 估值与基本面大致匹配 | 上行与下行空间均有限 |
| 减持 | 估值偏高或基本面走弱 | 盈利下修、份额流失、杠杆过高 |
| 卖出 | 结构性问题或严重高估 | 商业模式受损、流动性/偿债危机 |

评级须与「风险」「未来三年增长点」章节逻辑自洽。

## 各章节展开提示

### 公司介绍
- 一句话定位（「XX 行业的 XX 类型公司」）
- 关键里程碑：IPO 时间、重大并购、业务 pivot
- 当前规模：TTM 营收、员工数（如有）

### 商业模式
- 画布式描述：客户 → 渠道 → 产品 → 收入 → 成本结构
- 是否 B2B / B2C / B2B2C；合同周期（一次性 vs 订阅）

### 收入来源
- 表格示例：

| 业务线 | 占比 | YoY | 备注 |
|--------|------|-----|------|
| ... | ...% | ...% | ... |

### 盈利模式
- 单位经济（如适用）：ARPU、CAC、LTV、产能利用率
- 与同业利润率对比

### 管理层
- 表格示例：

| 姓名 | 职位 | 任期 | 背景要点 |
|------|------|------|----------|
| ... | CEO | ... | ... |

### 行业地位
- TAM/SAM/SOM（有来源则引用）
- 市占率趋势：扩大 / 稳定 / 收缩

### 核心竞争优势
- 每条格式：**优势** — 证据 — 可持续性（强/中/弱）

### 风险
- 格式：**[高/中/低] 风险名称** — 描述 — 潜在影响

### 未来三年增长点
- 建议按时间线：

| 时间 | 增长点 | 确定性 | 潜在影响 |
|------|--------|--------|----------|
| 2026 | ... | 高/中/低 | ... |
| 2027 | ... | ... | ... |
| 2028 | ... | ... | ... |

### 投资评级
结尾结构：
1. **评级**：买入（示例）
2. **目标价/估值**：$XX–$XX 或 EV/Revenue X–Xx
3. **核心逻辑**（bullet 3–5 条）
4. **关键假设**：什么必须成立评级才有效
5. **证伪条件**：什么发生应下调评级
